# Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/kneelinghorse/TraceLab/security/advisories/new) to report a suspected security issue in TraceLab or its MCP package. Private vulnerability reporting is enabled for this repository.

Include the affected version or commit, the affected component, a minimal reproduction and the impact you observed. Redact passwords, API keys, session tokens and other people's personal data. Do not put vulnerability details or credentials in a public issue.

For ordinary bugs and feature requests, use [GitHub issues](https://github.com/kneelinghorse/TraceLab/issues).
