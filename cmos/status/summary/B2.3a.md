# B2.3a – Markdown Ingestion Pipeline

- Node-based ingestion service created under `services/markdown-ingestion/` with watcher, worker, and backfill commands.
- Unified/remark chunker preserves heading trails, computes stable chunk hashes, and writes Qdrant payloads with OpenAI embeddings.
- Telemetry counters/histograms instrumented via OpenTelemetry API; documentation updated with configuration and runtime guidance.
