## Sprint Evaluation Script

Run the Sprint Efficacy Evaluator to generate retrospective reports:

```bash
python scripts/evaluate_sprint.py --sprint 1
```

The script:
- Ingests mission metadata from `cmos/missions/backlog.yaml`
- Consumes telemetry artifacts from `cmos/reports/sprint-01/`
- Evaluates success criteria against measured metrics
- Generates a Markdown report at `cmos/reports/sprint-01/sprint-XX-summary.md`

For JSON output:
```bash
python scripts/evaluate_sprint.py --sprint 1 --format json
```

**Usage:** Execute at the end of each sprint to assess mission completion and inform next-sprint planning.
