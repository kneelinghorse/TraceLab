## 1. Mission scope (as planned)

**T46.1** — make `authorize()` (`app/core/authorization.py`) correctly resolve every resource
type when `rbac_enabled=True`, while remaining a byte-identical no-op when `False`. Per the
resolved scope (CMOS decision #260): orphan `project_id=NULL` missions/reports = **fail-closed**
(owner+admin only); collections = workspace-membership; no route changes in this mission.

## 2. What the code review found

`authorize()` was **already correct** for:
- `rbac_enabled=False` → returns `True` (no-op).
- owner / admin role → allow.
- `resource.owner_id == user.user_id` → allow.
- Space membership via `_effective_space_id` (child `project_id` → `project.workspace_id`
  inheritance), failing closed when no DB session is passed.
- **Collections** (no `project_id` column) → resolved via their own `workspace_id`. ✓ matches
  decision #260(a).

**The one gap:** `_effective_space_id` used `getattr(resource, "project_id", None)`. That returns
`None` **both** when the attribute is absent (top-level `Project`/`Collection` — should use own
`workspace_id`) **and** when the column is present but NULL (orphan `Mission`/`Report` — should
fail closed). So an orphan would fall through to `getattr(resource, "workspace_id", None)` and be
authorized via the child's **own** workspace membership — violating decision #260(b).

**Model facts verified (grep):** `Project`/`Collection` have **no** `project_id` column;
`Mission`/`Report` have `project_id` (nullable) **and** their own `workspace_id`; `Document` has
`project_id` **NOT NULL** (cannot be an orphan).

## 3. The change (now reverted)

In `_effective_space_id`, replace the ambiguous `getattr(..., None)` with a sentinel:

```python
_NO_PROJECT_FK = object()

project_id = getattr(resource, "project_id", _NO_PROJECT_FK)
if project_id is _NO_PROJECT_FK:      # top-level (Project/Collection) → own workspace_id
    return getattr(resource, "workspace_id", None)
if project_id is None:                # ORPHAN child → fail closed
    return None
# child with a real project_id → inherit owning project's workspace_id (unchanged)
project = db.get(Project, project_id)
return getattr(project, "workspace_id", None) if project is not None else None
```

Net effect: an orphan mission/report resolves to `None` → no membership → **deny** for
non-owner/non-admin. The orphan's **owner** is still allowed (via the earlier `owner_id` branch);
owner/admin roles via the role short-circuit. A small `authorize_or_403` helper was also added
(intended for T46.2 route wiring) — also reverted.
